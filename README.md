# FORMWORK — 建築模型列印工作室

瀏覽器本機運算的建築模型轉換工具。匯入 STL／OBJ，輸出毫米制、Z 軸向上的二進位 STL；模型不傳送到伺服器。

```sh
npm install
npm run dev
npm test
npm run build
```

## 操作

1. 匯入封閉網格，確認原始單位與比例，設定列印平台。
2. 視需要開啟「只保留外立面」：水平切面填補內部孔洞，封閉小於設定值的開口，保留指定深度的外層細節。
3. 設定噴嘴、壁厚警戒值、懸垂角與支撐尺寸，點「自動加厚、擺放與生成支撐」。
4. 比較修正前後，查看紅色薄牆、橘色懸垂與青色支撐。可以一鍵還原；原始檔不會修改。
5. 匯出模型與支撐的組合 STL、模型單獨 STL 或支撐單獨 STL。分開匯入切片軟體時必須保留共同原點，不要分別自動置中。可另存 JSON 檢查報告。

## 實作與限制

- Three.js 預覽，Manifold WebAssembly 做實體驗證、布林合併及加厚；運算在 Web Worker，可因參數變更取消。
- 匯入上限 25 MB／200,000 三角面。開口、非流形網格需在原建模軟體修復；不讀取 SKP、RVT、IFC、照片或平面圖。
- 壁厚以最多 3,000 個三角面中心向內射線估算，並非完整厚度場，可能漏掉局部細節。自動加厚採整體 Minkowski 外擴，會改變外尺寸與縮小孔洞，最多兩輪；上限 20,000 面。修正後重新取樣，保留未解決的警告。
- 自動擺放比較六個軸向，在平台可容納的方向中選擇較少懸垂面積的姿態；不是任意角度全域最佳化。
- 懸垂門檻為表面與水平面的角度。向下表面低於設定值時標示；忽略平台接觸面，未模擬逐層島嶼與橋接能力。
- 支撐由朝下面的面中心與平面網格取樣建立，往下連到平台或模型上表面，保留設定接觸間隙；較高的柱子加寬底部。從支撐幾何扣除模型，避免填滿模型內部。最多 1,200 根／20,000 個平面取樣點，超過會明確回報。柱狀支撐可能側向接觸，並未評估密閉空間可拆除性、支撐自身列印穩定度或完整逐層覆蓋；不是切片器的樹狀支撐引擎。
- 外立面模式保留原始外牆，再以水平分層填補內部（最多 800 層／20,000 面）。外輪廓仍可凹入，並非凸包。窗洞與天井可能被封閉，分層可能產生階梯；大於封口門檻的開口可能仍留下內部空間。實心幾何可由切片器使用稀疏填充，並不等於 100% 材料填充。
- 有風險時需檢閱後才能匯出。輸出不含 G-code 或印表機設定，仍須在切片器確認接觸間隙、層高、支撐拆除及逐層預覽；尚未做實體列印驗證。

## 驗證

`npm test` 驗證 STL 單位／座標軸、無效與開口輸入、薄牆加厚、支撐封閉性與接觸間隙、自動方向、外立面填實及凹輪廓保留、底座合併。正式打包使用 `npm run build`。

此環境無 in-app browser，未執行瀏覽器互動與視覺 QA。可選的 WebMCP 比例控制已做 feature detection，但沒有可用的 WebMCP 驗證環境。

幾何引擎：[Manifold](https://manifoldcad.org/docs/jsapi/)。列印參考：[Prusa 建模指南](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135)。設定值是可調的初始值，不能取代實際噴嘴、材料與冷卻能力的校準。
